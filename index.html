🌙
Apps Script 웹앱 URL
구글 시트에서 Apps Script 배포 후 URL을 붙여넣으세요.
설정하면 스크립트·P/F 데이터를 시트에서 자동 로드하고 별점 변경 시 시트에 바로 저장돼요.
사용 방법
1. 구글 드라이브에서 엑셀 파일 열기 → 구글 시트로 저장
2. 확장 프로그램 → Apps Script 열기
3. apps-script.js 코드 전체 붙여넣기
4. 배포 → 새 배포 → 웹앱 → 액세스: 모든 사용자
5. 배포 URL을 위에 붙여넣고 저장
